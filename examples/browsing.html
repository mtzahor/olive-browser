A few useful shortcuts

Cmd/Ctrl+L selects the address. Cmd/Ctrl+R reloads. Alt+Left and Alt+Right move through history.

You followed a fragment link.

Links can point to a section of the current page without making another network request.

Web pages currently show HTML, embedded CSS, and image alt text. Remote scripts, external resources, and forms are not supported yet.
